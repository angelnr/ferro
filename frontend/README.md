# Ferro · frontend

PWA Angular 22 (standalone, signals, zoneless) con Tailwind CSS 4 y Vitest.

```bash
# desde la raíz del repo; no requiere Node en el host
make install          # npm ci en Docker
make fmt              # Prettier
make verify-frontend  # formato + ESLint + Vitest con cobertura + build
```

Reglas de trabajo, arquitectura y protocolo de evidencia: [../AGENTS.md](../AGENTS.md).
El contrato de la app está en [../docs/](../docs/).
